
# Former

Former je besplatna Firefox ekstenzija koja
blokira pristup sajtu Informer i odabranim
profilima na društvenim mrežama.

## Privatnost

Former je namenjen blokiranju određenih
stranica bez praćenja korisnika.

## Instalacija za razvoj

1. Preuzmite izvorni kod.
2. Otvorite about:debugging u Firefoxu.
3. Izaberite "Load Temporary Add-on".
4. Učitajte manifest.json.

## Status

Projekat je u aktivnom razvoju.
