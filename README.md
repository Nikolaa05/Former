## Former

Former je besplatna Firefox/Chrome ekstenzija koja blokira pristup sajtu Informer i odabranim profilima na društvenim mrežama.

## Instalacija

Former je dostupan za Firefox i Chrome pregledače.

### Firefox

**Status:** Čeka odobrenje na Firefox Add-ons.

**Zvanična instalacija:** Link će biti dodat nakon objavljivanja.

**Ručna instalacija za testiranje:**

1. Preuzmite izvorni kod projekta preko GitHub opcije **Code → Download ZIP** i raspakujte ga.
2. Otvorite Firefox i unesite `about:debugging#/runtime/this-firefox`.
3. Kliknite **Load Temporary Add-on**.
4. Izaberite `firefox/manifest.json`.

Napomena: Ova instalacija je privremena i uklanja se nakon ponovnog pokretanja Firefoxa. Za trajnu instalaciju biće dostupna potpisana verzija na Firefox Add-ons.

### Google Chrome

**Status:** Verzija 1.1.3 - Odobrena

**Chrome Web Store:** [Instaliraj Former za Chrome](https://chromewebstore.google.com/detail/former/hbaaemaajfmomdaonglgbibbbboepnel) 

**Ručna instalacija:**

1. Preuzmite izvorni kod projekta preko **Code → Download ZIP** i raspakujte ga.
2. Otvorite Chrome i idite na `chrome://extensions`.
3. Uključite **Developer mode**.
4. Kliknite **Load unpacked**.
5. Izaberite folder `chrome/`.
